# Subsurface downloads

Subsurface is a free macOS app for exploring installed software, commands, and AI skill libraries.

[Download the latest release](https://github.com/scottreyes/subsurface-releases/releases/latest)

Requires macOS 15 or later. Release downloads support Apple Silicon and Intel Macs.

## Install or update

1. Download the ZIP for your Mac and unzip it.
2. Quit any running copy of Subsurface.
3. Drag Subsurface into Applications, replacing the previous version when updating.

These early builds are ad-hoc signed and have not been notarized by Apple. macOS may require manual approval before opening them.

Subsurface can check for new releases from its app menu or Settings and download a verified ZIP. Installation remains manual.

This repository contains public app downloads and release notes. The source repository is maintained separately. The first release will appear after the publishing setup is complete.
